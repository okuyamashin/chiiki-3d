# 上小阿仁村：産業・通勤・集落・人口の調査メモ

調査日：2026年11月13日。動画の台本に先立つ資料整理。数値は記載年の実績で、現在値とは限らない。

## 分かったこと

国有林関係の雇用が縮小した山村で、限られた農地の維持、小規模な製造業、村外への通勤が暮らしを支えている。製造業の存在は確認できるが、昔の林業を代替する規模の産業が育った、とまでは確認できない。村の存立や全世帯の所得を説明するには、年金・財政移転など別の資料も必要である。

「村内の仕事」と「村民の仕事」、「就業者数」と「生産・販売の金額」を分けて扱う。

## 1. 製造業：チップと柵の2社だけではなかった

秋田県「2021年 秋田県の工業」統計表4の上小阿仁村欄を確認した。

| 産業中分類 | 事業所 | 従業者 |
|---|---:|---:|
| 食料品 | 1 | 6人 |
| 木材・木製品 | 1 | 15人 |
| 家具・装備品 | 1 | 9人 |
| 金属製品 | 1 | 11人 |
| 合計 | 4 | 41人 |

製造品出荷額等は44,340万円（約4.43億円）、粗付加価値額は10,763万円（約1.08億円）。出荷額は利益でも住民所得でもない。

これは**個人経営を除き、従業者4人以上等の条件を満たす製造事業所**の集計であり、村内製造業の全数ではない。従業者等は2021年6月1日現在、出荷額等は2020年実績。業種別の出荷額は秘匿されている。

出典：[秋田県・2021年の製造業集計](https://www.pref.akita.lg.jp/pages/archive/71263)の「4 統計表」CSV、統計表4、および「1 利用上の注意」。取得した原本は `data/raw/research_05327/manufacturing_2021.zip` に保存。

### 日本機械工業・三意工場

- 企業自身のJ-GoodTech掲載情報によれば、**1987年に秋田県の誘致工場として創設**。
- 秋田県北部テクノプラザの会員名簿は、工場名に対して「防雪柵・立体駐車場等」と記載。
- 秋田県機械金属工業会の紹介は、会社全体について鉄鋼・建材企業の委託加工工場と説明し、「納入先」と「取引先」を分けている。鉄鋼企業を一律に仕入先と決めることもできない。
- ただし会社全体の納入先や施工実績を、三意工場固有の出荷先・実績として扱わない。古い会社名を含む紹介であり、現在の契約関係も断定しない。
- 統計上の金属製品1事業所・11人を、この工場だと名寄せする根拠は未取得。

出典：[企業自身のJ-GoodTech紹介](https://jgoodtech.smrj.go.jp/corp/info/JC0000000044830?createdLocale=ja_JP&preview=false)、[北部テクノプラザ会員名簿](https://www.hokubu-technoplaza.com/index.php/list/4-2015-04-21-18-35-04)、[秋田県機械金属工業会・会員紹介](https://www2.chuokai-akita.or.jp/kikai/member/akitashi-23.htm)。

地元専用工場か、村外向け工場か、具体的な輸送経路・採算・誘致時の立地選択理由は公開資料だけでは確定できなかった。

## 2. 通勤：村外の仕事も無視できない

| 指標 | 2020年 |
|---|---:|
| 村民の就業者総数 | 876人 |
| 村内で働く村民 | 555人 |
| 他市区町村へ通勤する村民 | 313人 |
| 他市区町村から村へ通勤 | 191人 |
| 従業地による村内就業者数 | 754人 |

村外通勤者は村民の就業者総数の約35.7％。555＋313と876の差などは、従業地・常住地不詳等を含む集計上の残差として残し、無理に配分しない。

出典：[総務省統計局「統計でみる市区町村のすがた2026」](https://www.stat.go.jp/data/s-sugata/pdf/all_shi.pdf)、上小阿仁村、F2701・F2705・F2801・F2803（PDF 198ページ）、F1102（就業者総数）。総数876人は既存の国勢調査小地域産業データとも一致。

行き先は、村の人口ビジョンに載る**2010年**の県内通勤では北秋田市281人、秋田市25人、大館市19人など。北秋田市が中心だったことは分かるが、これを2020年の行き先別人数として使わない。

出典：[村の人口ビジョン](https://www.vill.kamikoani.akita.jp/div/kikaku/pdf/kikaku/senryaku/kami-jinkoubijon01.pdf)、本文8ページ・図表13。

村民の製造業就業者128人（2020年）から、工業集計の41人（2021年）を引いて「87人が村外通勤」としてはいけない。年次・集計対象が異なり、村外からの通勤者も混在する。製造業に限る常住地×従業地の照合は未完了。

## 3. 林業：国有林の雇用縮小が大きい

村の計画に載る林業就業者は、1975年536人、1990年244人、2000年85人、2015年35人。村は国有林経営の合理化と外材輸入による木材産業の長期低迷を要因に挙げる。木材関連製造業の縮小に加え、2009年度には縫製工場2つが工場統合により村外へ撤退したと記載する。

これは雇用の縮小を示す。森林資源や木材生産そのものが消えたという意味ではない。現在の木材販売量・林業所得や機械化の寄与は別途必要。

出典：[村の過疎地域持続的発展計画](https://www.vill.kamikoani.akita.jp/div/kikaku/pdf/kasotiikizizokutekihattenkeikaku.pdf)、本文8〜9ページ。

## 4. 農業：少ない平地と、散らばった農地を維持する難しさ

2024年度の水田収益力強化ビジョンは、山間の傾斜地で、大区画化・機械大型化が難しいと説明。農地の引受けは担い手に集中して飽和状態だが、まとまった場所へ集約できていない。農業収入の大部分は稲作。そば・大豆もあり、野菜は新規取組者が少なく、冬の除雪も栽培を制約する。

出典：[上小阿仁村農業再生協議会・2024年度水田収益力強化ビジョン](https://www.maff.go.jp/tohoku/seisan/suiden_kosyueki/attach/pdf/syuuekiryoku_kyouka-577.pdf)、本文1〜2ページ。

2023年の農業産出額は**推計4.1億円**、県内25市町村中25位。利益・農家所得ではなく、別年の製造品出荷額と単純比較して村の稼ぎを算出しない。

出典：[東北農政局秋田県拠点・2025年春号](https://www.maff.go.jp/tohoku/tiiki/akita/attach/pdf/akitanews-37.pdf)、2ページ。

地形上の説明は「農業をする場所がない」ではなく「村の広さに対して農地が限られ、その維持も難しい」。小沢田・福舘などの平地と、山間の農地を分けて見せる。

## 5. 集落移転：現在の無人地を、昔からの無人地と思わない

村の過疎計画は、奥地の小集落で就労機会の不足や若年層転出、老人世帯増加があり、昭和50年代前半に6集落が移転したと記載。各集落名・移転先・年は同資料からは確定できない。

出典：[村の過疎地域持続的発展計画](https://www.vill.kamikoani.akita.jp/div/kikaku/pdf/kasotiikizizokutekihattenkeikaku.pdf)、本文2ページ。

萩形については、ダム建設に伴う住民移転があった。秋田公立美術大学の研究紀要は1966年完成の萩形ダムと集落38戸の移転・転出に言及する。大学の研究論文には、その後の集落再編成事業による移転も指摘されている。林業衰退だけに原因をまとめず、水没・個別転出・集団移転を区別する。

出典：[秋田公立美術大学研究紀要第5号](https://www.akibi.ac.jp/akibi_cms/assets/uploads/2018/04/2017kiyou.pdf)、[立命館言語文化研究36巻3号・萩形についての論考](https://ritsumei.repo.nii.ac.jp/record/2001809/files/07_lcs_36_3_sumida.pdf)。本文全体の再確認と、歴史資料による移転年・位置の照合は必要。

現在の小地域10区分は実際の集落より大きい。2000年以降の小地域人口だけでは、それより前の集落移転を再現できない。

## 6. 人口減少：若者の流出と自然減の両方

2016年の人口ビジョンは、10代後半〜20代前半の転出超過が大きく、1992年以降自然減が継続すると説明する。同資料の2015年以降の人口は推計を含むため、実績と取り違えない。

出典：[村の人口ビジョン](https://www.vill.kamikoani.akita.jp/div/kikaku/pdf/kikaku/senryaku/kami-jinkoubijon01.pdf)、本文11・43ページ。

より最近の村広報では、**2025年1〜12月の出生3人、死亡51人**。差は48人の自然減となる。これだけから社会増減や総人口減少は計算できない。

出典：[広報かみこあに・2026年2月号](https://www.vill.kamikoani.akita.jp/div/kikaku/pdf/kouhou/20262kouhou8-14.pdf)、9ページ。

## 台本への反映案

1. 村全体の山地を見せ、川沿いの平地と集落へ寄る。
2. 国有林関係の仕事と、その雇用縮小を示す。
3. 農業と製造業は存在するが、土地と雇用規模に制約があることを説明する。
4. 村外への通勤を示し、生活圏が村境を越えることを伝える。
5. 年齢構成の変化と自然減へつなげる。過去の集落移転は位置・時期を確定した場合だけ補う。

## 残る確認事項

- 三意工場固有の出荷先・従業員数・輸送と立地選択の詳細。
- 製造業128人の村内勤務／村外勤務別内訳、2020年の通勤先別人数。
- 個人・小規模事業所を含む村内製造業の全数。4事業所の統計を全数と誤認しない。
- 移転6集落の名称・時期・位置・移転先。萩形ダム関連移転と混同しない。
- 農業者の年齢構成、現在の販売額・所得、林業生産量と所得。
- 年金や財政移転など、就業統計に表れない生活を支える所得。現状の調査から「産業がない」「村が成り立たない」とは断定しない。

公開資料で確認した範囲のメモであり、企業・役場等への問い合わせは行っていない。
